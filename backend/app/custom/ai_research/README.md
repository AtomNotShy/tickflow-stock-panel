# AI 研究池扩展

该扩展在每日行情管道成功落盘并刷新缓存后自动运行一个研究 Agent。它不会接收手工股票列表，候选来自本地最新行情的流动性、动量、放量、突破和涨停等异常，以及需要持续复核的既有论点。

## 当前数据边界

- 行情与技术指标：复用 `KlineRepository` 的 enriched 点时数据。
- 财务：仅使用研究日当时已经公告的本地财务记录。
- 新闻与宏观事件：当前项目没有这类标准数据源，因此首版不会伪造外部新闻。Agent 提示词明确限制为本地量价异常；以后接入新闻 Provider 时，应先标准化事件时间、来源和发布时间，再合并到同一自动输入列表。
- AI 输出：同一个研究 Agent 将候选按小批次生成结构化决策，避免完整候选列表挤爆单次输出上限；严格 schema 校验，只允许返回输入中的 `(symbol, anomaly_key)`，并要求每个输入都有且只有一条决策。任何编造标的、遗漏候选、重复身份或字段漂移都会整次失败关闭。

## 两本账

1. `selection_outcomes`：每个首次进入 `eligible` 的论点都记录 1/3/5/10/20 个交易日的次日开盘至期末收盘收益，并在沪深 300 数据可用时计算同期超额收益，用来衡量 AI 选股本身。
2. 模拟账户：受资金、最大持仓数、100 股整数手、次日开盘、停牌、一字涨跌停、佣金、印花税和滑点约束，用来衡量完整执行流程。

候选身份是“异常论点 + 股票”，同一股票可以有多个论点；模拟账户按股票聚合，只持有一个仓位。

## 生命周期与失败策略

- 候选：`discovered/analyzed/watching/eligible` → `expired/invalidated/rejected/stale`。
- 模拟订单：`pending` → `filled/cancelled`；退出信号也在下一交易日开盘尝试成交。
- 入池阈值与持仓退出阈值分开，降低边界抖动；证伪和硬风险直接退出并进入冷却期。
- AI 未配置、超时或输出非法时，不生成新候选，也不因 AI 缺席强制卖出；止损和最长持有期等确定性风控仍会运行。
- 每个交易日只有一个已完成的正式运行，重复触发幂等；进程重启会把遗留的 `running` 标成失败，允许重试。

数据存储在 `data/user_data/ai_research.sqlite3`，schema 迁移是幂等的。当前方法版本为 `ai-research-v1`。
